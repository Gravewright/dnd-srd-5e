# DnD 5e SRD 0.1.2 Alpha

Character, monster and item sheets use less empty space while keeping interface
text at least 12px. Actor and token windows initially use at most 1000 × 760px,
adapting to smaller viewports. The overview has a shorter banner, compact ability
and combat cards, shorter skill rows and life controls beside their values.
Empty collections follow their content instead of stretching to fill a panel.
Spacing and corner tokens are defined inside the system package.

Roll windows open at the height their controls require. Character and monster
skills sort alphabetically by their translated name in the active language.
Each skill has a selector for its saved default ability; the roll window also
allows an ability override for that check alone. Proficiency, expertise, passive
values, effects and relevant armor penalties use the effective ability. The new
schema field is optional, so existing sheets retain their usual ability until a
selection is saved. Both 2014 and 2024 editions remain available.

All eleven item types have compact headers and detail groups, smaller empty
textareas and related fields grouped together. Long descriptions and properties
use the available width and remain scrollable. Standalone editors and copies
owned by actors keep their fields, saving and reading permissions. Item names
sort inside their existing category or spell-level groups, and descriptive
choices use their translated labels. Presentation sorting does not rearrange
saved collections or modify item copies. Weapon and spell ability selectors
retain their existing behavior.

Native movement, resizing, keyboard focus, Escape and closing remain available.
Use **Reset window layout (↺)** in a title bar to replace an older saved layout
with the compact default.

## Install and compatibility

Install **DnD 5e SRD 0.1.2** from the signed Marketplace under **Systems**, or
download `gravewright-5e-srd-0.1.2.zip` and its SHA-256 sidecar from the
[source release](https://github.com/Gravewright/dnd-srd-5e/releases/tag/v0.1.2).
Select the exact version in the table's **Settings → Extensions**.

The system remains one browser package for the published Gravewright VTT
**0.2.3**, SDK **1.x**, without a host patch or separate Server Rules module.
English is the default. Official Translator **0.1.2 or newer** provides account
language selection for English, Brazilian Portuguese and Spanish.

Unpublished local review builds are consolidated into this release. If another
local 0.1.2 is already installed, first switch affected tables to another
installed version, remove that local build with native package management, then
install the public 0.1.2. The host preserves immutable ID/version pairs and will
reject different bytes for an installed pair. Higher local review versions need
manual selection of 0.1.2 rather than an automatic update.

The **20 partial licensed SRD packs / 2,535 entries**, artwork, source digests,
IDs and license notices are unchanged. No rulebook, PDF or premium content is
added. Existing campaign data, settings and authored content remain in place.
The shared native item directory and compendium browser belong to the VTT;
their separate host interface changes are not included in this system ZIP.

## Português brasileiro

Fichas de personagens, monstros e itens ocupam menos espaço vazio, com texto da
interface de no mínimo 12px. Janelas de personagens e tokens abrem inicialmente
com até 1000 × 760px, adaptando-se à tela. A visão geral usa cabeçalho mais baixo,
cartões compactos de atributos e combate, linhas de perícia menores e controles
de vida junto dos valores. Coleções vazias acompanham seu conteúdo. Os tokens
de espaçamento e cantos são definidos no próprio pacote do sistema.

Janelas de rolagem abrem com a altura necessária aos controles. Perícias de
personagens e monstros ficam em ordem alfabética pelo nome traduzido no idioma
ativo. Cada perícia permite salvar seu atributo padrão; a janela de teste também
permite escolher outro atributo apenas para aquela rolagem. Proficiência,
especialização, valores passivos, efeitos e penalidades relevantes de armadura
consideram o atributo efetivo. O novo campo é opcional: fichas existentes mantêm
o vínculo habitual até o usuário salvar uma escolha. As edições 2014 e 2024
continuam disponíveis.

Os onze tipos de item têm cabeçalhos e grupos de detalhes compactos, áreas de
texto vazias menores e campos relacionados reunidos. Descrições e propriedades
longas aproveitam a largura disponível e mantêm rolagem. Editores independentes
e cópias na ficha preservam campos, salvamento e permissões de leitura. Nomes
ficam em ordem alfabética dentro dos grupos existentes de categoria ou nível de
magia; escolhas descritivas usam os rótulos traduzidos. A apresentação não muda
a ordem salva nem modifica cópias de itens. Seletores de atributo de armas e
magias conservam seu funcionamento.

Movimento, redimensionamento, foco pelo teclado, Escape e fechamento nativos
continuam disponíveis. Use **Redefinir layout da janela (↺)** na barra de título
para aplicar o padrão compacto no lugar de um tamanho antigo salvo.

Instale **DnD 5e SRD 0.1.2** pelo Marketplace assinado em **Sistemas**, ou pelo
ZIP e checksum da release, e selecione essa versão em **Configurações →
Extensões** da mesa. Funciona no VTT **0.2.3 já publicado**, SDK **1.x**, em um
único pacote para navegador. Não exige patch no host nem Server Rules separado.
Inglês é o padrão; o Translator oficial **0.1.2 ou mais recente** permite escolher
o idioma na conta.

Os builds locais de revisão foram reunidos nesta versão. Se outra 0.1.2 local
já estiver instalada, selecione outra versão instalada nas mesas afetadas, remova
aquele build pelo gerenciador nativo e instale a 0.1.2 pública. O host não
sobrescreve o mesmo ID/versão com bytes diferentes. Builds locais com numeração
maior exigem selecionar a 0.1.2 manualmente.

Os **20 pacotes parciais de SRD / 2.535 entradas**, imagens, hashes, IDs e avisos
de licença permanecem iguais. Nenhum livro, PDF ou conteúdo premium é adicionado.
Campanhas, configurações e conteúdo escrito pelo usuário são preservados.
O diretório nativo de itens e o navegador de compêndios são fornecidos pelo VTT;
as mudanças separadas dessas interfaces não integram este ZIP de sistema.
