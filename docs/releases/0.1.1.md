# DnD 5e SRD 0.1.1 Alpha

DnD now installs as **one browser system package** on the published Gravewright
VTT **0.2.3**, using the existing SDK 1.x. Character, monster and item sheets,
settings, translations, licensed compendiums, initiative and turn automation all
belong to `gravewright.5e-srd`. No VTT patch or separate Python module is required.

Download `gravewright-5e-srd-0.1.1.zip` and its SHA-256 sidecar from the
[release](https://github.com/Gravewright/dnd-srd-5e/releases/tag/v0.1.1). Install
under **Systems**, select this version for the table and use its combat tracker
as GM. English is the default; the official Translator supplies interface language
selection for English, Brazilian Portuguese and Spanish.

The existing **20 partial SRD packs / 2,535 entries** remain unchanged: 1,259
entries for 2014 and 1,276 for 2024, including 319 and 338 spells. Licensed text,
IDs, source digests, provenance and notices are preserved. Compendium descriptions
stay English; no new rulebooks, PDFs, official artwork or premium content is added.

Persisted operation plans and native revisions resume unfinished combat steps
without repeating completed work. Different sheets use recoverable writes, not
one shared transaction. Moving backward does not undo outcomes. Automation does
not run after all table clients close.

For an older Server Rules installation, **Customize → Previous installation**
lets the host owner review deactivation and the existing restart flow. Removing
the previous module requires another confirmation with affected tables. Existing
system IDs, authored sheet data, embedded items and settings remain in place.

## Português brasileiro

O DnD passa a ser **um único pacote de sistema para o navegador**, compatível
com o Gravewright VTT **0.2.3 já publicado** e SDK 1.x. Fichas de personagens,
monstros e itens, opções, traduções, compêndios, iniciativa e automações ficam
em `gravewright.5e-srd`, sem patch no VTT nem módulo Python separado.

Instale `gravewright-5e-srd-0.1.1.zip` em **Sistemas**, selecione esta versão
para a mesa e use seu tracker como mestre. Inglês é o padrão; o Translator
oficial permite escolher o idioma da interface. Os **20 pacotes parciais do
SRD / 2.535 entradas** mantêm seus textos, IDs, procedência, hashes e licenças.
O conteúdo dos compêndios continua em inglês. Nenhum material novo é adicionado.

Planos persistidos e revisões nativas permitem retomar operações de combate,
sem transação única entre fichas nem execução depois que todos fecham a mesa.
Uma instalação antiga do Server Rules pode ser revisada pelo proprietário em
**Personalizar → Instalação anterior**; desativação e remoção exigem escolhas
separadas. Fichas e dados existentes permanecem no mesmo namespace.
