# DnD 5e SRD 0.2.0 Alpha

## Monster compendiums and player item drops

- Include 317 SRD 5.1 monsters and 330 SRD 5.2.1 monsters, separated by edition, with licensed content and attribution.
- Let players copy readable compendium items into editable character sheets through authorized reads, without creating library items.
- Keep library imports and Effects GM-only and preserve campaign data and the stable system ID `gravewright.5e-srd`.
- Validate the browser system against Gravewright VTT 0.3.5 while retaining the 0.2.3 baseline. On 0.3.5, item and spell packs are readable by players by default unless the GM changes permissions; monster packs require GM sharing.

## Installation

Download `gravewright-5e-srd-0.2.0.zip` and verify its SHA-256 sidecar. Install through the VTT local system installer, select version 0.2.0 in the table extensions and reload open tables. Keep previous versions for rollback. No separate Server Rules module is required. Marketplace availability depends on its catalog. Compendium content remains English; the interface supports translation through the official Translator.

## Português brasileiro

Esta versão inclui 317 monstros do SRD 5.1 e 330 do SRD 5.2.1, separados por edição, com conteúdo licenciado e atribuição. Jogadores podem copiar itens legíveis dos compêndios para fichas editáveis, sem criar itens na biblioteca. Importações para a biblioteca e Efeitos permanecem exclusivos do mestre.

O sistema é validado com o VTT 0.3.5 e mantém a base 0.2.3. No 0.3.5, itens e magias ficam legíveis aos jogadores por padrão, salvo alterações de permissões pelo mestre; monstros dependem de compartilhamento. Dados de campanha e o identificador do sistema são preservados.

Baixe `gravewright-5e-srd-0.2.0.zip`, confira o SHA-256, instale pelo instalador local de sistemas, selecione 0.2.0 nas extensões da mesa e recarregue as mesas abertas. Preserve versões anteriores para reversão. Não é necessário módulo separado de Server Rules. A disponibilidade no Marketplace depende do catálogo. O conteúdo dos compêndios continua em inglês; a interface usa o Translator oficial.
