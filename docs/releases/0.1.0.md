# DnD 5e SRD 0.1.0 Alpha

First public release for Gravewright VTT. The browser system and its server companion both use version **0.1.0**.

[Português brasileiro](#português-brasileiro) · [Release and downloads](https://github.com/Gravewright/dnd-srd-5e/releases/tag/v0.1.0) · [Installation guide](../../README.md)

## English

### Downloads and requirements

| Asset | Install as |
| --- | --- |
| `gravewright-5e-srd-0.1.0.zip` | **System**: DnD 5e SRD |
| `gravewright-5e-srd-server-0.1.0.zip` | **Module**: DnD 5e SRD - Server Rules; explicitly enable the trusted Django extension |
| Each ZIP's `.sha256` file | Verify the corresponding archive's SHA-256 before local installation |

Requires **Gravewright VTT 0.2.1 or newer**, SDK 1.x. Use **official Translator 0.1.2 or newer** for Brazilian Portuguese or Spanish; English is the fallback. The host owner must install and activate the server companion, completing the managed Runner restart. Both packages are also listed in the [official Marketplace](https://github.com/Gravewright/marketplace).

The display name is **DnD 5e SRD**. Technical IDs `gravewright.5e-srd` / `gravewright.5e-srd-server` and ZIP filenames are retained for continuity. This release does not rename existing table documents or change their rules edition.

### Included

- Selectable **2014 / SRD 5.1** and **2024 / SRD 5.2.1** profiles, with a GM default for new sheets and an explicit edition on each sheet.
- Noturno character and monster sheets; eleven native item editors; responsive windows, configurable portraits, automatic saving, revision checks and save-before-close behavior.
- Ability checks, saving throws, skills, expertise, passive values and spellcasting; public/GM chat rolls with advantage/disadvantage and extra modifiers.
- HP, temporary HP, armor/shield calculations, declared equipment passives, attunement, death/concentration handling, initiative and supported periodic/expiry effects.
- Edition-specific short/long rests, Hit Dice, spell slots, Pact Magic, exhaustion and inspiration behavior, and explicit resource recovery.
- Direct compendium/library drag and drop, correct item routing, required choices before applying origin/class advancement, starting equipment and grants with provenance.
- **Twenty partial SRD packs, 2,535 entries**: 1,259 from 2014 and 1,276 from 2024, including 319/338 spells. English text, traceable sources and preserved licenses.
- English, Brazilian Portuguese and Spanish interface through the official Translator API. User content and English compendium descriptions remain unchanged.
- All D&D rules live in the system or its companion. The VTT core supplies only generic provider, document, permission and persistence contracts.

### Limits and compatibility

This is an **Alpha** release. Compendiums are partial and include variants; they are not advertised as the complete SRD. There are no monster compendiums, ready-made effect packs, official artwork, books, PDFs, premium packs or Foundry runtime assets.

Automation applies supported declarative metadata, not arbitrary rule prose. Contextual decisions, Weapon Mastery, targeting/areas, target saving throws, components, ammunition and unrepresented exceptions remain manual. Changing the sheet edition does not convert imported items. Updating a pack does not rewrite copies already embedded in sheets. Legacy campaigns are not imported automatically. See the detailed [automation reference](../../AUTOMATION.md) and [content coverage](../../compendiums/README.md).

VTT 0.2.0 is insufficient even though its SDK number is 1.0.0. Update the VTT first. Without the trusted companion, system-owned initiative and turn automation cannot run; installing the browser system alone does not enable Python code.

### Installation and upgrades

1. Back up the VTT database, media and configuration. Install/update VTT to 0.2.1 or later.
2. Install both 0.1.0 packages through the Marketplace or native local-package installer.
3. As host owner, activate **DnD 5e SRD - Server Rules** as trusted Django code and finish the Runner restart.
4. Install/activate Translator for localized use; select your account language and reload.
5. Create a table using **DnD 5e SRD**. The GM sets the default rules edition and compendium permissions; each sheet can retain its own edition.

Keep browser and companion versions aligned. When moving an existing development installation to this release, preserve the VTT's database/media/module storage. Technical IDs remain stable. A code rollback is not a data rollback: restore a consistent backup when reverting data changes as well.

### Incluído

- Regras de D&D exclusivamente no sistema e no companion. O core do VTT oferece contratos genéricos de providers, documentos, permissões e persistência.

### Limites e compatibilidade

Esta é uma versão **Alpha**. Os compêndios são parciais e incluem variantes; não representam todo o SRD. Não há compêndios de monstros, pacotes de efeitos prontos, artes oficiais, livros, PDFs, conteúdo premium ou runtime do Foundry.

A automação aplica metadados declarativos compatíveis, não toda descrição de regras. Contextos, Maestria, alvos/áreas, salvaguardas dos alvos, componentes, munição e exceções sem representação continuam manuais. Trocar a edição não converte itens importados. Atualizar um pacote não reescreve cópias já incorporadas nas fichas. Campanhas legadas não são importadas automaticamente. Veja [automações e limites](../../AUTOMATION.md) e [cobertura do conteúdo](../../compendiums/README.md).

O VTT 0.2.0 não é suficiente, mesmo mantendo SDK 1.0.0. Atualize o VTT primeiro. Sem o companion confiável, a iniciativa e as automações de turno do sistema não podem executar; instalar apenas o pacote de navegador não ativa código Python.

### Instalação e atualização

1. Faça backup da base de dados, mídia e configuração. Instale/atualize o VTT para 0.2.1 ou posterior.
2. Instale os dois pacotes 0.1.0 pelo Marketplace ou pelo instalador nativo de pacotes locais.
3. Como proprietário do host, ative **DnD 5e SRD - Server Rules** como código Django confiável e conclua o reinício do Runner.
4. Instale/ative o Translator para localização; escolha o idioma na conta e recarregue.
5. Crie uma mesa com **DnD 5e SRD**. O mestre define a edição padrão e permissões dos compêndios; cada ficha mantém sua escolha.

Mantenha sistema e companion na mesma versão. Ao substituir uma instalação de desenvolvimento, preserve o armazenamento de dados, mídia e módulos do VTT. Os IDs técnicos continuam iguais. Reverter código não reverte os dados: restaure um backup consistente se precisar voltar também o estado da campanha.
