# 0.1.3 — Local update / Atualização local

Players may drop readable compendium items onto sheets they can edit. Reads
remain server-authorized; no campaign library documents are created. Effects
and library imports remain GM-only. On unmodified Gravewright 0.3.4, the GM
must grant compendium read access. Install the ZIP and select 0.1.3 in
Settings → Extensions, then reload open tables.

Jogadores podem soltar itens de compêndios legíveis nas fichas que podem editar.
A leitura permanece autorizada pelo servidor, sem criar documentos na biblioteca.
Efeitos e importação para a biblioteca continuam exclusivos do mestre. No
Gravewright 0.3.4 sem a alteração local, o mestre precisa liberar a leitura.
Instale o ZIP, selecione 0.1.3 em Configurações → Extensões e recarregue a mesa.
